# Personal Portfolio Website
## Overview
This project is my personal portfolio website, created to showcase my technical projects,
coding growth, and professional background. The goal of the site is to give recruiters,
employers, and collaborators a central place to learn more about my work and experience.
## Features
- Professional introduction and background section
- Project showcase area for technical work
- Clean layout designed for readability and easy navigation
- Responsive design for desktop and mobile viewing
- Contact or profile links for professional networking

## Tech Stack
- HTML
- CSS
- JavaScript
## Purpose
I built this project to create a professional online presence and to practice organizing
information in a clear, user-friendly format. It also gave me experience designing a site
around real career goals instead of only classroom requirements.
## What I Learned
Through this project, I strengthened my skills in front-end development, layout design,
content organization, and building a website with a professional purpose.
